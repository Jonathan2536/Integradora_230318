# Integradora_230318

Repositorio de prácticas de análisis, modelado y representación visual de sistemas y modelos de negocio.

## Descripción

Este proyecto reúne dos prácticas desarrolladas como páginas web interactivas. Cada práctica cuenta con su propio README, archivos de trabajo y acceso a su versión publicada en GitHub Pages.

## Prácticas disponibles

### Práctica 02 - Diagrama de Arquitectura con Archify

Representación visual de la arquitectura propuesta para un sistema móvil. El diagrama organiza la capa móvil, autenticación, API, datos, servicios externos e infraestructura de desarrollo.


### Práctica 03 -  Model Canvas de Spotify

Análisis del modelo de negocio de Spotify mediante los nueve bloques del Business Model Canvas: socios, actividades, recursos, propuesta de valor, clientes, canales, costos e ingresos.

## Tecnologías y herramientas

- HTML5 para las páginas interactivas.

- JavaScript para las interacciones del Canvas.
- Archify para el modelado del diagrama de arquitectura.
- GitHub Pages para la publicación de los resultados.
